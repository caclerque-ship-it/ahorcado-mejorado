# 🎯 Juego del Ahorcado (versión mejorada)

Versión mejorada del clásico **Ahorcado en Python**, creada por **Cristian Clerque**.  
Incluye nuevas características, puntuación, dificultad, pistas y estadísticas.

---

## 🚀 Características principales

- Selección de dificultad (fácil, media, difícil)
- Sistema de puntuación y bonificaciones
- Guardado automático de puntuaciones (`score.txt`)
- Historial de partidas (`history.txt`)
- Pista por partida (-2 puntos)
- Soporte para lista de palabras externa (`words.txt`)
- Totalmente jugable desde consola

---

## 🧩 Requisitos

- Python 3.7 o superior  
- Sistema operativo: Windows, Linux o macOS
